# 556 Drop

1. 3D Printed Drop Payload
The '3D Printed Drop Payload** is a modular payload device designed to use a **5.56 blank** as a propulsion mechanism. This particular model is equipped to function with a **M3x8 screw**, and can optionally hold **chalk''' for marking targets upon impact. The design is intended for safe deployment in various environments, such as during Minecraft simulations, where it is particularly effective on hard surfaces.

### Components
Here are the components that make up this modular drop payload:

- Nosecone: `PD_Nosecone_33.8.stl`

- 5.56 Pusher: `1-12pusher556.stl`

- Drop Tail: `JP_DROP_TAIL_1-12.stl`

- Ring: `PDRING1-12.stl`

### Features

- **Modular Design**: The payload is designed to be easily assembled and disassembled.

- **Safety**: Built to ensure safe drops onto targets with minimal risks.

- **Material**: Fully 3D printed for rapid prototyping and adaptability.

- **Usage**: Can be loaded with chalk for marking or other materials depending on the operational needs.

### Performance
Based on field tests (conducted within Minecraft simulations), the payload works well on hard targets, such as vehicles or solid ground. However, its sensitivity is reduced when impacting soft surfaces like dirt, making it more effective for specific deployment types.

### Future Development

- **Evolving Design**: The design has evolved from previous iterations used in ODB and is continually improved for better performance and reliability.

- **Potential Upgrades**: Future iterations might include more modular options and varied payload capacities.
