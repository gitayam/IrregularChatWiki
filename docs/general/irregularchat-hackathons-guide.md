# IrregularChat Hackathons/Guide

:zap: **Irregular Hacks: Hack Sprint #2 (3:30–6:30 PM)**

No intros. Quick + dirty. Ship something useful.

1. 3:30 – 3:45 PM — Setup & Tool Sync

- Verify GitHub access and permissions

- Confirm IDE setup (Cursor, VSCode, etc.)

- Create or clone repo(s)

1. 3:45 – 4:05 PM — Project Selection & Lock-In

- Review last week’s project board and survey ideas

- Vote and pick 1 project to build today

- Define success: "If we get X working, that’s a win."

1. 4:05 – 4:25 PM — MVP Scope & Task Breakdown

- Define features/components to build today

- Assign tasks

- Identify known blockers early

1. 4:25 – 6:15 PM — Code Sprint

- Heads down coding

- Real-time commits, PRs, and updates

- Check-in as needed in voice/chat

1. 6:15 – 6:30 PM — Demo & Debrief

- Share what’s working or broken

- Talk next steps and follow-ups

1. 6:30 PM+ — Keep Hacking (Optional)

- Teams can continue post-event as long as they want

- Stay on call or async
