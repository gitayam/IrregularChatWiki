# Creating an Intellipedia Page for a TAAW

## Intellipedia Workflow: Creating an Intellipedia Page for a TAAW

### Step 1: Search for Your Refined Target Audience

Search your refined target audience for the page you wish to create in the search bar.

**Example:** U.S. Citizens 18-25 that attend AC/DC concerts in City X, Country Y

- Intellipedia will prompt the user to create a page that does not exist. This will show up as red text.
- Click the link to create the page.

### Step 2: Select Create View

Ensure that you are in the *Create* view and not the *Create Source* view in the top right below your username.

### Step 3: Add Heading

Use heading font with this formula (see [Editing on Intellipedia](https://socom.sharepoint-mil.us/sites/socsouth-j3-jedpsyop/SiteAssets/SOCSOUTH%20J39%20PSYOP%20(CUI)/MISO/SOPs%20and%20Guides.one)):

**TAAW supporting MISO Series: *SERIES NAME* (*COUNTRY NAME*).**

### Step 4: Add Source Documentation Link

Hit enter and in paragraph font, provide a link to source documentation:

"Link to *Series Name* (*COUNTRY ABBREVIATION*) here."

*We will come back to this at the end.*

### Step 5: Save the Page

Click save page to create the page (others can now edit after this action).

- In the window that populates, select the correct classifications for each section.
- Write a brief description summarizing the changes made in the summary box provided at the bottom.
- Click OK.
- Now click edit in the top right below the username.

### Step 6: Set Classification

1. Click the classification to the left of the title to change it to the proper classification if needed.
2. Click the classification banner above/below the page content.
3. Click the proper classification.
   - If the proper caveat is not listed, click add/edit/delete while highlighting the classification.
   - Go to the dissemination tab and select the proper classification caveat (this is the overall classification of the document).
   - Scroll down and click OK.
   - Then click Apply.

### Step 7: Add MISO Series Header Data

Write "MISO Series Header Data" (Sub-heading 3).

- Underneath that, write the header data (MO, SMO, TA, RTA) (paragraph font).
- Ensure that sources are included at the end of each line if needed.
- Ensure that proper classification is included formatted as such:

**MO: (U//FOUO) MO: *MO definition here* (*Source and MO*).**

- Link the source to the source page on Intellipedia if it exists.

### Step 8: Add Content Sections (Achievability - Refined Assessment Criteria)

For the next sections:

- Use **Heading** for each major section (e.g., Conditions or Accessibility).
- Use **Sub-heading 2** for second-level indented information bullets.
  - Supporting information should be in paragraph font.
- Use **Sub-heading 3** for third-level indented information bullets.
  - Supporting information should be in paragraph font.
- To insert pictures into sections (e.g., Symbols), see [Editing on Intellipedia](https://socom.sharepoint-mil.us/sites/socsouth-j3-jedpsyop/SiteAssets/SOCSOUTH%20J39%20PSYOP%20(CUI)/MISO/SOPs%20and%20Guides.one).

### Step 9: Add References Section

On a new line, write "References" (Heading font). See [Citations in Intellipedia](https://socom.sharepoint-mil.us/sites/socsouth-j3-jedpsyop/SiteAssets/SOCSOUTH%20J39%20PSYOP%20(CUI)/MISO/SOPs%20and%20Guides.one).

- Create a numbered list by typing "1." and then hitting the space bar to format it.
- Start the reference with the format:
  - (Classification letter) - *Name of the reference goes here* *Specific paragraph and line numbers go here*.
- Link the reference title to the reference document using the techniques from earlier in the workflow.

**To link a reference:**

1. Highlight the title of the reference.
2. Click link in the toolbar and then link.
3. Click External Site and copy/paste the URL of the source document from where you found it on the portal or the website that it was found on.

### Step 10: Create Footnotes

1. Highlight the word here.
2. Click link button (looks like two chain links) in the toolbar and then link.
3. Click OK Got it.
4. Click External Site and copy/paste the URL of the TAAW into the text bar.
   - This should be the URL from where the TAAW is officially kept in the Portal.
   - (Pending or approved, this link will be updated as needed).

### Step 11: Final Save

1. Click done.
2. Hit save in the top right to create the page.
   - Write a brief description summarizing the changes that you have made in the summary box that is provided at the bottom.
   - Click Save changes in the top right to save.

### Step 12: Link to Main Page

Once finished, go to [Linking an Intellipedia page to a main page](https://socom.sharepoint-mil.us/sites/socsouth-j3-jedpsyop/SiteAssets/SOCSOUTH%20J39%20PSYOP%20(CUI)/MISO/SOPs%20and%20Guides.one) to link this page to the 1st POB consolidated knowledge on Intellipedia.

## Optional: Add Links Section

*This is not required but may be needed.*

On a new line, write "Links" (Heading font).

- Provide links to all cross-referenced information in Intellipedia.
- Create a numbered list by typing "1." The format should look as follows:
  - (Classification letter) - *LINK TITLE GOES HERE*.
- Link the phrase to the other existing pages using techniques from earlier in the workflow.

**To link to another Intellipedia page:**

1. Highlight the title of the reference.
2. Click link in the toolbar and then link.
3. Click Intellipedia and type the page that you wish to reference in the search bar and click it.
