Cloud certifications are among the highest-ROI credentials for transitioning military — especially with a security clearance. A cleared cloud engineer in the DC metro averages $173k.

---

## Certification Paths

### AWS

| Cert | Cost | Level | Best For |
|---|---|---|---|
| Cloud Practitioner (CLF-C02) | $100 | Entry | Any background — start here |
| Solutions Architect Associate (SAA-C03) | $150 | Intermediate | Architects, highest job volume |
| Solutions Architect Professional | $300 | Advanced | Senior roles ($155k-$170k) |
| ML Engineer Associate | $150 | Specialty | AI/ML roles (replaces ML Specialty March 2026) |

### Azure

| Cert | Cost | Level | Best For |
|---|---|---|---|
| AZ-900 Fundamentals | $99-$165 | Entry | Microsoft/.mil shops |
| AZ-104 Administrator | $165 | Intermediate | IT admins |
| AZ-305 Architect | $165 | Advanced | Architects ($140k-$165k) |

### GCP

| Cert | Cost | Level | Best For |
|---|---|---|---|
| Cloud Digital Leader | $99 | Entry | Business/strategy |
| Associate Cloud Engineer | $200 | Intermediate | DevOps/engineering |
| Professional Cloud Architect | $200 | Advanced | Highest salary ceiling ($139k-$175k) |

### Vendor-Neutral

| Cert | Cost | Level | Notes |
|---|---|---|---|
| CompTIA Cloud+ | $369 | Intermediate | Good for DoD baseline |

## Which Cloud to Choose?

- **AWS**: Largest job market share (3x more openings than GCP). Best overall bet.
- **Azure**: Dominates enterprise and DoD environments. Best match for veterans from .mil IT shops.
- **GCP**: Best for data engineering and AI/ML. Smaller talent pool = salary premium.
- **Multi-cloud**: 92% of enterprises run multi-cloud. Multiple certs = best mobility.

## Free Military & Veteran Programs

### AWS
- [AWS re/Start](https://aws.amazon.com/training/restart/) — 12-week free cloud training with job placement
- [AWS Educate](https://aws.amazon.com/education/awseducate/) — free for veterans and spouses
- [AWS Skill Builder](https://skillbuilder.aws/) — free self-paced training
- [GI Bill Exam Reimbursement](https://aws.amazon.com/certification/veterans-reimbursement/) — submit VA Form 22-0803
- [Cloud Veterans](https://www.cloudveterans.org/) — nonprofit for military cloud careers
- [Army COOL: AWS Cloud Practitioner](https://www.cool.osd.mil/army/credential/index.html?cert=accp8363)

### Microsoft
- [MSSA](https://military.microsoft.com/mssa/) — 17-week free program (Cloud Dev, Server Admin, Cybersecurity). SkillBridge-eligible.
- [Microsoft Learn](https://learn.microsoft.com/) — free self-paced training
- AZ-900 virtual training events frequently include **free exam voucher**

### Google
- [Google Career Certificates](https://grow.google/expanding-opportunity/military-community/) — free through military partnerships
- [Google Cloud Training](https://cloud.google.com/training) — free tier
- [Google Cloud Launchpad for Veterans](https://cloud.google.com/blog/topics/training-certifications/google-cloud-launchpad-veterans-to-cloud-careers)

### Discounted Exams
- [Pearson VUE Government Store](https://govstore.pearsonvue.com/) — AWS, CompTIA, Microsoft, Cisco at discount

## Best MOS Fit

| MOS/Rate | Recommended Path |
|---|---|
| 25-series (Signal) | CompTIA Net+/Sec+ → AWS SAA → Cloud Engineer |
| 17-series (Cyber) | Sec+ → AWS Security Specialty or AZ-500 |
| Navy IT/CT rates | CompTIA trifecta → AWS or Azure path |
| Air Force 1D7/3D | AWS + Azure + clearance leverage |

## Certification Stacking

- **AWS SAA + Sec+ + TS/SCI** = cleared cloud engineer ($120k-$175k)
- **AWS ML Engineer + Sec+ + clearance** = cleared AI/ML ($130k-$180k)
- **AZ-104 + AZ-500 + clearance** = cleared Azure security ($115k-$160k)
