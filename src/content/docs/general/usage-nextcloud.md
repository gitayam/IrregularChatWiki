# Usage - Nextcloud

### Apple
This works for macOS and iOS devices.

The following apps can sync with NextCloud instead of or along with iCloud: - Files - Download the NextCloud App - Contacts - Go to Settings &gt; Contacts &gt; Accounts &gt; Add Account &gt; Add CardDAV Account - Recommend you disable iCloud contact sync - Calendar - Go to Settings &gt; Calendar &gt; Accounts &gt; Add Account &gt; Add CalDAV Account - Enable Calendar and Reminder Sync - Recommend you disable iCloud Calendar and Reminder sync - Reminder - See Calendar Instructions
