# Remove self from email Distros

1. Open the Global Federated User Directory (GFUD) website: [https://portal.apps.deas.mil/](https://portal.apps.deas.mil/). It works best with Chrome or Edge!
2. Click on "My Self-Service"
3. Double-click on "My Distribution Lists"
4. This page shows every distro list you are associated with
5. Click on the red icon to remove yourself from that particular distro list.
6. The "Status" column will reflect "Pending Delete" as it takes 24-48hrs for changes to take effect.
