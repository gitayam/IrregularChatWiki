# Fabrication

**Manufacturing** is producing goods using equipment, labor, machines, tools, and chemical or biological processing or formulation. It is the essence of the secondary sector of the economy. [- Wikipedia](https://en.wikipedia.org/wiki/Manufacturing)

For community knowledge management, fabrication and rapid prototyping are used to plan, establish, use, and counter fabrication for unique training and operational problem sets.

### Unclassified and Useful 3D Print Files

To upload a print file:

1. Make sure you are logged into the wiki
2. Select "Upload file" from the right toolbar
3. Upload one (1) file at a time giving it a descriptive name and description
4. Add the **3D Print File** category
5. If you think the file should be limited to logged-in users, add the **Login Required** category

| Category | Context |
|----------|---------|
| SUAS Mounts | This category will require login |
| Delivery Devices | This category will require login |

## Requested Files

To request a file:

1. Check if the file exists yet in the community or on the open web
2. Check if the file has been requested on the [forum here](https://forum.irregularchat.com/tag/fabrication)
3. Create a new topic (this will automatically be sent to the Signal and Matrix chatrooms)
   - Use a descriptive name
   - Select the proper category
   - Add the **Fabrication** tag and others as appropriate
   - In the body, describe the context, references, similar projects, specifications, and what success looks like
4. Add a request to the table below and link to the forum
