# Join

1. 🛡 Irregular Chat Sign-In

1. 🌐 Overview
[Irregular Chat Single Sign-On (SSO)](/general/the-irregularchat-login) login allows users to access all community applications, websites, and data with a single login, ensuring convenience and enhanced security. This system utilizes a self-hosted Authentik or Github Group for authentication.

1. ❓ Why Use Single Sign-On?
Identify Provider, Single sign-on (SSO), simplifies the login process for users by requiring them to authenticate just once to access various services and platforms.
