# Research Tools

## Research Tools

### Research Repositories and Toolkits

- [Bellingcat toolkit](https://bellingcat.gitbook.io/toolkit/most-used) - Bellingcat toolkit that stays updated.

- [Intelx Search Tools](https://intelx.io/tools?tab=person) – Useful for finding personal data, historical records, and more.

- [Inteltechniques Search Tools](https://inteltechniques.com/tools/Name.html) – Specializes in people searches and social media data.

- [Intelx Google Dork Knowledge Management](https://intelx.io/dorks) – Resource for understanding and using Google Dorks in OSINT research.

- [STARTME OSINT Collection](https://start.me/p/b5Aow7/asint_collection) – Comprehensive OSINT tool collection for researchers.

- [OSINT Tool Collection](https://github.com/cipher387/osint_stuff_tool_collection) – Various tools for different OSINT purposes.

- [Flashpoint Tools Library](https://flashpoint.io/blog/osint-tools-library/) – Curated OSINT tools and techniques

### Community Projects

- [Google Scraper](https://github.com/agile-enigma/google_scraper) – Scrape and organize Google search results efficiently.

- [Research Tools](https://researchtools.net) – A hub for various research repositories.

- [Pulse Query Generator](https://github.com/irregularchat/pulse-menu) – Generates queries for advanced data searches and analysis.

### Search Platforms

- [NewsData.io](https://newsdata.io/search-news) API and Dashboard to get news from any country in chronological order. The dashboard works without a login.

- [ThreatMapper](https://github.com/deepfence/ThreatMapper) – Runtime Threat Management and Attack Path Enumeration for Cloud Native environments.

- SearXNG ([community instance](https://search.irregularchat.com) | [public instance](https://searx.space) SearXNG is a free internet metasearch engine aggregating results from up to 211 search services. Users are neither tracked nor profiled. Additionally, SearXNG can be used over Tor to maintain online anonymity.

### Scraping
[Cobalt Tools](https://cobalt.tools) is used to download images and videos from many videos, social media, and other platforms using the web interface.

### Satellite and Geolocation Tools

- [Digisat Satellite Coverage Maps](https://www.digisat.org/satellite-footprint-maps) – Provides coverage maps for commercial satellite providers.

- [GEO SPY](https://geospy.web.app/) – AI tool used to estimate the location of where a picture was taken.

- [ARCGIS](https://qgis.org/en/site/) – Free version of ARCGIS, useful for making charts, maps, and geographical analysis.
